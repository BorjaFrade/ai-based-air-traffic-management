# Results

`results/` contains outputs generated by scripts, notebooks and experiments. It
is kept separate from both source code and input data so that generated material
can be identified and reproduced.

- `figures/`: maps, charts and other visual outputs. See
  [`figures/README.md`](figures/README.md).
- `tables/`: generated CSV, LaTeX or other tabular summaries.

Results should document their origin whenever possible: source dataset, script
or notebook, geographic area, observation time and relevant configuration.
Generated results must not be treated as raw input data.
